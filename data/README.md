# MNIST data

The MNIST handwritten digit database by Yann LeCun, Corinna Cortes and Christopher J.C. Burges,
derived from NIST Special Databases 1 and 3. It is commonly distributed under the
Creative Commons Attribution-Share Alike 3.0 license (CC BY-SA 3.0).

Downloaded from the mirror at https://ossci-datasets.s3.amazonaws.com/mnist/ and decompressed.
MD5 sums of the original .gz files matched the published ones.

The program reads these files from the current directory, so run it from this folder.
